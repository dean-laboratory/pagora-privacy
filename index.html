Pagora Privacy Policy

Effective date: November 9, 2026

This Privacy Policy describes how the Pagora application for Android (the "Application"), developed by pqzmggg (the "Developer"), handles information in connection with its use. The Application organizes the PDF and ZIP (CBZ) books stored in the user's Google Drive into a library and displays them for reading.

1. Information Collected by the Developer

The Developer does not collect, receive, or have access to any personal information of users. The Developer operates no servers for the Application, and the Application requires no account other than the user's own Google account. All information described in this Policy is processed on the user's device or exchanged directly between the device and Google. If the user turns on the external AI described in Section 3, information is also exchanged directly between the device and the AI company the user has chosen. The Application contains no advertising, analytics, or crash reporting components.

2. Google Account and Google Drive Data

When the user chooses to connect Google Drive, the Application requests read-only access to the user's Google Drive (the drive.readonly scope) through Google's authorization service. The Application does not receive or store the user's Google password.

With this access, the Application uses the following Google Drive data solely to provide its features to the user:

  1. The names, folder locations, sizes, modification times, checksums, and thumbnail images of PDF and ZIP (CBZ) files, and the names and structure of folders, in order to find books, build the library, and sort books into categories automatically on the device.
  2. The contents of the files that the user chooses to download, in order to keep them on the device and display their pages. When the user has read most of a volume in a series, the Application may download the next volume of the same series in advance.
  3. The first part of PDF files and parts of ZIP (CBZ) files, in order to create cover images and to read the text at the beginning of books for sorting them.

To sort books whose category cannot be determined from their file names, the Application reads the text at the beginning of the book (text contained in the PDF, or text read from the cover image by on-device text recognition). The Application may give book titles and this text to an on-device language model (a model that the user chooses to download). This processing takes place entirely on the device; unless the user turns on the external AI described in Section 3, titles and text are not transmitted to the Developer, to Google, or to any other party.

By default the Application looks only at files in the user's own My Drive. Files and folders that other people have shared with the user are read only when the user selects those folders in the Application.

The Application only reads Google Drive data. It does not create, modify, move, or delete any file in the user's Google Drive. Google Drive data is requested by the device directly from Google and is not transmitted to the Developer. Except when the user turns on the external AI described in Section 3, it is not transmitted to any other party.

The Application's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google Drive data is not used for advertising, is not sold, and is not read by any person.

3. External AI (Only When Turned On by the User)

In the advanced settings of the Application's AI classification screen, the user may register the user's own API key and turn on classification by an external AI (Claude by Anthropic or ChatGPT by OpenAI). This feature is off by default and works only after the user turns it on and saves an API key.

  1. Information sent: the titles of the books to be classified, part of the text at the beginning of those books (up to 80 characters per book), and the list of categories needed for the request. The user's Google account information, the book files themselves, and reading history are not sent.
  2. Recipient: the API of the company the user has chosen (Anthropic or OpenAI). The device sends requests directly to that company, without passing through the Developer. The information sent is handled under that company's privacy policy (Anthropic, OpenAI) and the API terms the user has agreed to with that company.
  3. Purpose: to determine the categories of the books. The answers (categories) are stored only on the device.
  4. API key: encrypted with an Android Keystore key on the device and kept only in the Application's private storage; it is not transmitted to the Developer. Usage is billed to the account of the API key.
  5. Stopping: the user may turn off the external AI or delete the API key at any time in the advanced settings, after which no information is sent.

4. Permissions and Their Purposes

  1. Internet access: to obtain authorization from Google and to read the list and contents of files in the user's Google Drive, and to download the list of on-device language models and, when the user chooses, a model file. These downloads contain no information about the user. When the user turns on the external AI described in Section 3, also to request classification from that AI.

5. Information Stored on the Device and Its Deletion

For its operation, the Application retains the following information solely in the Application's private storage on the user's device:

  1. The library: the file information described in Section 2(1), the text at the beginning of books, the categories assigned to each book, reading positions and progress, and bookmarks.
  2. Books that the user has downloaded, so that they can be read on the device, and cover images, kept as a cache to display the library quickly.
  3. Reader settings and whether Google Drive has been connected.
  4. The external AI settings described in Section 3 and the API key (stored encrypted).

Application backup is disabled, and this information is therefore not copied to any cloud backup. The user may delete a downloaded book at any time by long-pressing it in the library, and may delete all such information at any time by clearing the Application's storage or by uninstalling the Application. Books that are no longer found in Google Drive are removed from the library 30 days after they disappear.

6. Revoking Access

The user may disconnect Google Drive within the Application at any time. The user may also revoke the Application's access to the Google account at any time on the Google Account third-party access page. After access is revoked, the Application can no longer read Google Drive data.

7. Disclosure to Third Parties

The Developer does not provide, sell, or transfer any information to third parties. Requests for authorization and for Google Drive data are sent only to Google and are handled under the Google Privacy Policy. However, when the user turns on the external AI described in Section 3, the device sends the information described in Section 3(1) directly to the AI company the user has chosen.

8. Children

The Application is not directed at children, and the Developer does not collect information from any person, including children.

9. Changes to This Policy

Any amendment to this Privacy Policy will be published on this page together with its effective date.
